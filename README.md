# Tilt Rider

A kid-friendly 3D motorcycle racer for iPad, phones and desktop. Built with three.js, as plain static files.

- Steer by tilting your device. There are touch buttons and a keyboard too (←/→ steer, ↑ gas, ↓ brake, Z/X kick, P pause).
- 5 tracks: Sunrise Coast, Red Rock Canyon, Neon City Night, Pine Ridge and Frosty Pass.
- 8-rider races with cartoon kicks (BONK!). Riders tumble, get back up and keep racing.
- Garage with 5 bikes, paint, decals, helmet and jacket colors, and upgrades bought with race winnings.
- Progress is saved in localStorage.
